# Contributing

These manuals live in the [meatpi-docs](https://github.com/meatpiHQ/meatpi-docs) repository and are built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/). Every page has an edit link at the top right.

- Found a mistake or a step that did not work for you? Open an issue or send a pull request.
- Writing a new page? Read the [writing guide](writing-guide.md) first: it shows every building block (steps, screenshots, callouts, notes) and the house rules.
- Running the site on your own machine takes two commands; see the repository README.
